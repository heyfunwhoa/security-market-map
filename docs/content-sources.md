## Rules for turning these into content

- Use only reviewed, published claims. Candidate research notes stay internal until reviewed.
- Keep vendor-reported status, source and date attached when citing a vendor.
- Never call two vendors direct competitors because they share a category label.
- No private interview, employer or customer details.
- When a post ships, log it in the content tracker with the source file path. Do not add a post log to this repo.
