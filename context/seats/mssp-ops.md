# MSSP / MDR operations lead

Run detection and response for many customers; multi-tenant margin and tenancy drive evaluation.

## Typical titles

- ic: Managed Security Services Analyst, Managed Detection and Response Analyst
- senior-ic: Senior Managed Security Services Analyst, Lead Managed Security Services Analyst
- manager: Managed Security Services Manager, Managed Detection and Response Manager
- director: Director of Managed Security Services, Head of Managed Security Services
- vp: VP of Managed Security Services

## Owns categories

- Managed detection and response (`mdr`)
- SIEM (`siem`)
- SOAR and response automation (`soar`)
- Extended detection and response (`xdr`)
- Security data pipeline platforms (SDPP) (`security-data-pipelines`)

## Pains

- Per-tenant tooling cost squeezes margin — hypothesis
- Analyst staffing and retention — sourced ([SANS Institute](https://www.elastic.co/pdf/sans-soc-survey-2025.pdf))

## Objections

- "The per-tenant cost kills our margin." Usually about: Provider pricing has to fit their own packaging. Reframe to test: Model cost per tenant against analyst time saved, and check whether pricing matches how they bill clients. — hypothesis

## Qualification questions

- Does the provider manage security for many client tenants? Good fit if: Multi-tenant operations and per-client SLAs. (high weight, hypothesis)
- Is per-tenant tooling cost squeezing margin? Good fit if: Pricing that doesn't fit their packaging. (high weight, hypothesis)
- Does the provider resell a single vendor exclusively? Poor fit if: An exclusive partner agreement. (medium weight, hypothesis)
