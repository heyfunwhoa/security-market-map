# OT / ICS security

Secure plants, lines, and control systems where availability and safety come first.

## Typical titles

- ic: OT Security Engineer, ICS Security Engineer
- senior-ic: Senior OT Security Engineer, Staff OT Security Engineer, Principal OT Security Engineer
- manager: OT Security Manager, ICS Security Manager
- director: Director of OT Security, Head of OT Security
- vp: VP of OT Security

## Owns categories

- OT and IoT security (`ot-security`)
- Network edge (`network-edge`)
- Network detection and response (`ndr`)
- Microsegmentation (`microsegmentation`)

## Pains

- Can't patch or scan without risking downtime — hypothesis
- No complete asset inventory for plants and control systems — practitioner published ([ISA Global Cybersecurity Alliance](https://gca.isa.org/blog/isa-iec-62443-cited-in-cisa-ot-cybersecurity-guidance))

## Objections

- "We can't risk downtime on the plant floor." Usually about: Safety and production come before security. Reframe to test: Start with passive visibility that doesn't touch devices, and plan changes inside maintenance windows. — hypothesis

## Qualification questions

- Does the company run plants, utilities or connected devices? Good fit if: Industrial sites or medical or building systems. (high weight, hypothesis)
- Is remote access to OT increasing? Good fit if: Vendor remote access or IT/OT convergence projects. (medium weight, hypothesis)
- Are OT environments fully isolated with no remote access? Poor fit if: True air gaps. (low weight, hypothesis)
