# Security awareness

Training and simulated phishing for people. It changes behavior. It does not replace email security or identity threat detection.

**Buyer question:** Will people report the message, and is the program more than an annual video?

**Usual owner:** Security awareness, often under the CISO.

**Budget source:** Awareness, a small line next to email and identity.
