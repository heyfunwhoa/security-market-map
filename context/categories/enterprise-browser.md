# Enterprise browser

A managed browser as the work surface, used alongside virtual desktop and secure web gateway controls. This map keeps the browser as its own category. It still depends on workforce identity.

**Buyer question:** Is the control the browser, the network path, or the identity that opens the app?

**Usual owner:** IT security or the digital workplace team.

**Budget source:** Endpoint or secure access. Not the IdP renewal.

## Owning seats

- SaaS security (`saas-security`)

## What buyers do instead

- Managed standard browser with policies and extensions. Good enough when: Basic controls on managed devices are enough. Breaks when: Contractors, unmanaged devices, or data controls inside SaaS are required. — hypothesis
- VDI or remote desktop for risky access. Good enough when: A few high-risk user groups. Breaks when: VDI cost and user experience don't scale to everyone. — hypothesis
