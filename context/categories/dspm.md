# Data security posture

Discovery and classification of sensitive data in the stores a product can see, and the paths that can reach it. A posture finding is not a block on the way out. It is not an identity certification, and a CNAPP data module is a module until the order form says otherwise.

**Buyer question:** Where is the sensitive data, and which identities can reach it?

**Usual owner:** Data security.

**Budget source:** Data security. Watch for overlap with a CNAPP data module.

## Owning seats

- Data security (`data-security`)
- Privacy / DPO (`privacy`)
- SaaS security (`saas-security`)
