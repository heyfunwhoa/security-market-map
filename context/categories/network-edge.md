# Network edge

Firewalls, secure web gateways, ZTNA, and SASE. Buyers collapse these into one deal. They are not one control, and they are not a substitute for workforce identity.

**Buyer question:** What is allowed to connect, from where, and to which application?

**Usual owner:** Network security.

**Budget source:** Network security. Distinct from the IdP and from PAM.

## Owning seats

- IT / corporate security (`it-security`)
- Network security (`network-security`)
- OT / ICS security (`ot-security`)

## Vendors (primary)

- Zscaler: Security service edge vendor. Network-edge budget. Not an IdP, though it depends on one.
- Netskope: Security service edge vendor named beside Zscaler. Not an identity provider.
- Fortinet: Network security vendor on firewall and SASE shortlists beside Palo Alto Networks. Modules unverified.
- Check Point: Firewall and network security incumbent. A shortlist name, not a sourced feature comparison.

## Vendors (adjacent)

- Palo Alto Networks
- Cloudflare
- Illumio
- Island
- Forcepoint

## What buyers do instead

- VPN and perimeter firewalls kept as they are. Good enough when: Mostly office-based staff and few cloud apps. Breaks when: Remote work, SaaS, and edge-device vulnerabilities make the perimeter the weak point. — hypothesis
- Cloud provider network controls only. Good enough when: Workloads live in one cloud and users reach SaaS directly. Breaks when: User traffic, branch offices, and private apps need consistent policy. — hypothesis

## Objections

- "Our firewall vendor already covers this." — hypothesis

## Triggers

- VPN replacement
- Branch or SASE refresh
