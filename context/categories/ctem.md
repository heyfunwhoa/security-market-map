# Continuous threat exposure management

A program for deciding which exposures matter, broader than traditional technology vulnerability management. It is not itself a scanner, a cloud-posture product, or a software-composition scan.

**Buyer question:** Which exposures matter beyond the patch list, and who owns each one?

**Usual owner:** The exposure or vulnerability program, often beside cloud security.

**Budget source:** Often the vulnerability-management budget, sometimes cloud security. Ask which program is actually in scope.
