# AI data security

Sensitive data entering a prompt, retrieved by an agent, or leaving through a tool. This is data context for an AI workflow. It is not the same control as DSPM for data stores, and it is not agent identity.

**Buyer question:** Which sensitive data can this workflow see, and where can that data go?

**Usual owner:** Data security, with the team that runs the AI feature.

**Budget source:** Data security or AI security.
