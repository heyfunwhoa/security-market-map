# CIEM and access intelligence

Cloud entitlement posture and the question of effective access: what a human or machine can actually do across cloud accounts. This is not automatically an IGA certification product.

**Buyer question:** What can this identity really do in cloud, and which of those paths are excessive?

**Usual owner:** Cloud security, often a CNAPP owner, sometimes IAM.

**Budget source:** Cloud security or CNAPP, which is a different budget from classic IGA.

## Owning seats

- Identity security lead (`identity-security`)
- Cloud security (`cloud-sec`)

## Who vendors sell to

- None recorded.

## Vendors (primary)

- Veza: Access intelligence vendor. Buyers use this class of product to see effective permissions. This atlas does not treat Veza as a joiner-mover-leaver suite.
- Wiz: CNAPP vendor. Cloud entitlement conversations often happen here. That is adjacent budget to IGA, not a certification suite, unless a sourced claim says otherwise. Wiz markets a DSPM solution for cloud data security. Vendor-reported DSPM scope reviewed 2026-10-13.
- Sonrai Security: Cloud identity and entitlement candidate on CIEM shortlists beside Wiz and Veza. No permission graph is sourced.

## What buyers do instead

- Entitlement checks inside CSPM or CNAPP. Good enough when: One cloud and coarse least-privilege goals. Breaks when: Effective permissions across accounts and identities need to be explained and fixed. — hypothesis

## Triggers

- Overprivileged roles
- CNAPP renewal
- IAM wants effective access
